# Gentext — PWA для изучения грузского

## Как пользоваться

1. Положите файлы в папку.
2. Загрузите в GitHub Pages (Settings → Pages → Branch → `/ (root)`).
3. Откройте сайт на iPhone/iPad/Windows.
4. Выберите главу → уровень → режим (Список / Карточки / Тест).
5. Тест: спрашивается русский перевод, вы вводите грузинский.

## Структура данных

Каждая глава = одна таблица из ваших .md файлов.  
Уровень = подраздел таблицы (категория / ## заголовок).

## Офлайн

Service worker кэширует базовые файлы. Работает без интернета после первого визита.
