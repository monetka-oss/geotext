# Gentext — PWA для изучения грузского

## Как пользоваться

1. Откройте сайт на iPhone/iPad/Windows.
2. Выберите главу → уровень → режим (Список / Карточки / Тест).
3. Тест: спрашивается русский перевод, вы вводите грузинский.

## Структура данных

Каждая глава = одна таблица из ваших .md файлов.  
Уровень = подраздел таблицы (категория / ## заголовок).

## Офлайн

Service worker кэширует базовые файлы. Работает без интернета после первого визита.

## Лицензия

Бесплатно для личного использования.
